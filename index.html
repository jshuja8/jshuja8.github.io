I build machine learning for networked systems, and I study how AI can make students better software engineers rather than more dependent ones.

My research spans edge and cloud computing, deep reinforcement learning for computation offloading, IoT and blockchain security, and AI-assisted software engineering education. Research

My foundational work sits where machine learning meets computer networks, going back to my doctoral work on offloading for mobile cloud computing. More recently I have turned the same empirical lens on how generative AI changes the way software engineering is taught and how research itself is reviewed.

  • AI-assisted software engineering educationA Human-Grounded AI-Assisted framework that sequences manual and AI-assisted learning, piloted and measured across multiple semesters of CS445.
  • Edge computing and computation offloadingDeep reinforcement learning (Dueling DQN, PPO) and neural approaches for offloading decisions in mobile edge and vehicular networks.
  • Federated learning and intelligent IoTFederated learning for digital-twin vehicular networks, and UAV- and IoT-assisted monitoring architectures.
  • Security and blockchainLightweight encryption for IoT, tamper detection in sensor networks, and blockchain frameworks for traceability and trusted records.
  • AI and research integrityTelling authentic, generic, and AI-generated peer reviews apart, and asking whether AI-written reviews deserve trust.

Interested in working together? I welcome inquiries from students and collaborators in any of these areas.

Teaching

I teach systems, networks, security, cloud, and software engineering, and I am a Cisco-certified CCNA Instructor and AWS Academy Educator. My courses are project-based: students learn by building, and AI tools are introduced deliberately, after the fundamentals, not instead of them.

  • CS445 Software Engineering

    A semester-long team project course covering requirements, UML design, testing, and delivery. Home of the Human-Grounded AI-Assisted framework.

  • Operating Systems Online

    Processes, scheduling, memory management, concurrency, and file systems.

  • CY440 Cloud Computing (AWS Cloud Foundations)

    Core cloud concepts and services, taught with AWS Academy curriculum and hands-on labs.

  • Web Development and Security

    Building web applications and defending them against common attacks.

  • Intrusion Detection Systems

    Signature- and anomaly-based detection, network monitoring, and ML-driven IDS, within the cybersecurity curriculum.

  • Computer Networks

    Redesigned around active learning and gamification at Universiti Teknologi PETRONAS, published in the 2024 TLIF proceedings.

  • Generative AI New course in development

    A twelve-module course on foundation models, transformers, and building with generative AI responsibly.

I also run professional training, including a short course on data visualization and analysis for machine learning in Python for UTP's Centre for Advanced and Professional Education.
