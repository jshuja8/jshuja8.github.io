Research

My foundational work sits where machine learning meets computer networks. More recently I have turned the same empirical lens on how generative AI changes the way software engineering is taught and how research itself is reviewed.

  • AI-assisted software engineering educationA Human-Grounded AI-Assisted framework for teaching software engineering, piloted and measured across multiple semesters of CS445.
  • Machine learning for computer networksLearning-based approaches to traffic analysis, resource management, and anomaly detection.
  • Cloud and edge computingOffloading, orchestration, and fog/edge architectures for latency-sensitive and IoT workloads.
  • CybersecurityIntrusion detection systems and ML-driven threat detection, including federated approaches for IoT.
  • AI and research integrityWhether AI-generated peer reviews can be told apart from human ones, and whether they deserve trust.

Interested in working together? I welcome inquiries from students and collaborators in any of these areas.

Teaching

I teach systems, security, cloud, and software engineering. My courses are project-based: students learn by building, and AI tools are introduced deliberately, after the fundamentals, not instead of them.

  • CS445 Software Engineering

    A semester-long team project course covering requirements, UML design, testing, and delivery. Home of the Human-Grounded AI-Assisted framework.

  • [CS ###] Operating Systems Online

    Processes, scheduling, memory management, concurrency, and file systems.

  • CY440 AWS Cloud Foundations

    Core cloud concepts and services, taught with AWS Academy curriculum and hands-on labs.

  • Intrusion Detection Systems

    Signature- and anomaly-based detection, network monitoring, and ML-driven IDS, within the cybersecurity curriculum.

  • Generative AI New course in development

    A twelve-module course on foundation models, transformers, and building with generative AI responsibly.

  • Graduate Network Security In development

    A hands-on graduate course built around realistic attack-and-defend labs.
